Introduction to Linux kernel build configuration and modules

Fiquei travado no mount por um tempo ao fazer esse tutorial. 


        sudo --preserve-env make -C "${IIO_TREE}" modules_install
        sudo guestmount --rw --add "${VM_DIR}/arm64_img.qcow2" --mount /dev/ "${VM_MOUNT_POINT}"
O comando modules_install não funcionava, então usei o fuser para achar processo que estava com o write lock (igual o erro descrito no blog do tutorial 2). 


        sudo guestmount --rw --add "${VM_DIR}/arm64_img.qcow2" --mount /dev/ "${VM_MOUNT_POINT}"
Depois o comando acima deu erro indicando que o mountpoint não estava vazio. Então apaguei o diretório do mountpoint e criei de novo, aí o modules_install deu erro. O problema era que cd $VM_MOUNT_POINT retornava invalid argument. Para resolver, usei o fuser no mountpoint, vi que ele era um mount point controlado pelo kernel (esperado), logo o erro provavelmente era que o filesystem do mount estava corrompido. sudo umount -l /home/lk_dev/vm/arm64_rootfs, resolveu resolveu o problema.

De resto não tive problemas! achei a criação de módulos bem interessante, não imaginava que eles pudessem ser carregados no kernel enquanto ele estivesse rodando de forma tão fácil.
