Sending patches with git and a USP email

Não segui os quadrados amarelos já que pareciam desatualizados e não lembrava de terem sido mencionados na aula.

Ao tentar enviar o patch para mim mesmo com o email USP, recebi o erro: 


        No SASL mechanism found
        at /usr/share/perl5/Authen/SASL.pm line 76.
        at /usr/share/perl/5.38/Net/SMTP.pm line 211.
Li no repositório que era necessária versão 2.18+ da biblioteca perl's Authen::SASL para usar OAuth2.0. Então verifiquei a minha versão: 

        apt list | grep authen
        >libauthen-sasl-perl/noble,noble,now 2.1700-1 all [installed]
Como apt upgrade não funcionou (a versão do ubuntu limitou a versão da biblioteca), eu tive que consertar com 

        sudo apt-get install cpanminus
        sudo cpanm Authen::SASL
